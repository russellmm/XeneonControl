# Third-party notices

The Windows portable executable bundles Python 3.14 and Tcl/Tk 8.6, packaged with PyInstaller 6.22.3. Their notices accompany the Windows release in `third-party-licenses`. Python uses the PSF license; Tcl/Tk uses its permissive license; PyInstaller's bootloader is distributed under its license with the exception permitting generated application bundles.

The Ubuntu source release uses the Python/Tk, libusb, PyGObject, GTK, and Ayatana AppIndicator packages supplied by Ubuntu. libusb is loaded from the operating system and is not bundled. The application itself has no pip runtime dependencies.

No Corsair DLLs, device images, packages, or logos are included in either release. Device and product names identify compatibility; this utility is independent of Corsair.
